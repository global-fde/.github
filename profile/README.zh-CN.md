# Global FDE

[English](README.md) | [简体中文](README.zh-CN.md)

**全球 Forward Deployed Engineer 生态的可信连接器。**

Global FDE 连接企业需求方、FDE、AI 产品与工程团队、交付伙伴、技术厂商和行业专家，让知识、能力、人才与商业机会在可信关系中流动。

## 愿景

> 让全球每一个值得解决的 AI 落地问题，都能找到可信的人与能力；让每一位真正创造价值的 FDE，都能被看见、被连接，获得更大的机会。

## 使命

> 连接全球 FDE 生态，沉淀一线知识，验证真实需求与能力，促成跨组织、跨行业、跨地区的可信协作，让前沿 AI 转化为真实世界的结果。

## 价值观

- **真实问题优先**：从用户、流程、约束和可衡量结果出发。
- **证据胜过声量**：优先收录可验证的工作、具体系统和真实结果。
- **一线知识应当复利**：把交付经验沉淀为可复用的方法与资源。
- **信任先于交易**：披露利益关系，在商业合作之前建立可信连接。
- **保护现场信息**：未经授权，不公开客户数据、代码、合同和非公开业务信息。
- **全球连接，本地理解**：尊重语言、监管、行业和地区差异。
- **坦诚且慷慨**：分享不确定性、失败与能够帮助他人决策的经验。
